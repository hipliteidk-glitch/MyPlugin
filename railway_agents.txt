### 🚀 Why Railway for AI Agents?
The page highlights that Railway is built to support these agents with infrastructure that scales:
*   **Instant Scaling:** Scale from zero to thousands of instances, paying only for the compute you use.
*   **Persistent State:** Built-in Redis, Postgres, and Volumes for long-term storage and retrieval.
*   **Secure Execution:** Isolated environments, encrypted secrets, private networking, and SOC 2 compliance.
*   **CLI & MCP Access:** Full programmatic control via CLI and MCP server for terminal-based deployment.
*   **One-Click Templates:** Deploy full stacks with Postgres, Redis, MongoDB, and thousands of ready-to-use templates.
*   **Real-Time Observability:** Live logs, metrics, and traces for complete visibility into agent behavior.
*   **Instant Rollbacks:** Every deployment is versioned for easy rollbacks.
*   **Team Collaboration:** Shared projects, role-based access, and audit logs for team shipping.

### 🔍 How to Get Started
The page provides a simple starting point:
1.  **Deploy with one command:** Use `$ curl -fsSL agents.railway.com | sh` in your terminal.
2.  **Compare Agents:** Use the "Compare agents" feature on the page to find the right fit for your workflow.
3.  **Test the MCP Server:** Railway's Remote MCP Server is available for testing; learn more in their documentation.
